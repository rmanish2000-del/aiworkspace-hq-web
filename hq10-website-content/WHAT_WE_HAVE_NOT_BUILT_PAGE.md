# PAGE RULES

| # | Rule |
| --- | --- |
| **GAP-1** | **⛔ NO DATES. EVER.** *"We have not built X"* is honest. *"X is coming"* is a prohibited claim — P0 `01` §6. `CB-47` states this as a position rather than hiding it |
| **GAP-2** | **⚠ The page carries a review date and is re-verified quarterly.** A stale gap list becomes false in the other direction — claiming the absence of something that now exists |
| **GAP-3** | **⚠ It invites correction.** `CB-41` asks readers to tell us what is missing. **A page that asks to be corrected is much harder to disbelieve** |
| **GAP-4** | **⛔ Entries are removed only when the gap actually closes**, and the removal is dated in the page history |
| **GAP-5** | **⚠ The page never apologises and never explains itself away.** Each entry is a flat statement. Softening language is what makes a gap list read as a sales objection handled badly |
| **GAP-6** | **⛔ It is in PRIMARY navigation.** Not the footer, not a sub-page. **Placement is the strategy — N-1** |

# WHAT THIS PAGE DELIBERATELY DOES NOT DO

| | |
| --- | --- |
| **⛔ It does not rank the gaps by severity** | Ranking implies a work order, which implies a plan, which implies dates |
| **⛔ It does not explain why each gap exists** | An explanation reads as a defence. The statement is the content |
| **⛔ It does not promise to close any of them** | We have made four binding public commitments already. **We do not add a fifth by accident** |
| **⚠ It does not claim to be exhaustive — it claims to be honest** | `CB-41` says *"as complete as we can make it"*, which is a claim we can keep |
