# 1 ⛔ THE RULE THIS DOCUMENT EXISTS TO ENFORCE

> ## **A placeholder does not make a route buildable.**
>
> **A shell route has fewer than three `Verified` claims. Writing a sentence for it does not add evidence** — it adds a sentence. **IA-1 is unchanged by the existence of copy.**

**⚠ Rule SH-1: a shell placeholder is one honest line and a reason.** Not a "coming soon" page, not a teaser, not an email capture.

**⛔ Rule SH-2: a shell route is not in navigation unless HQ-9 puts it there**, and only `/docs` is — held in primary deliberately, marked as arriving with the product.
