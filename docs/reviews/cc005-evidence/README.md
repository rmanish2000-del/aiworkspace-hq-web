## DS-D1 implementation note

The storage amendment is enforced in two layers: ESLint unbans `localStorage`
only under `src/design-system/`, and the unit scope guard
(`tests/unit/copy.test.ts`) strips exactly
`localStorage.getItem('theme')` / `localStorage.setItem('theme', …)` inside
that directory before applying the storage ban — any other key, dynamic key,
`removeItem`, `sessionStorage`, or cookie still fails, everywhere. A new unit
test guards the stripper itself.
